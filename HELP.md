# Simple Line Editor - Help

## insert

Inserts a new line at the specified line number.

Syntax:
insert <line_number>

Example:
insert 2

The editor will ask for the text of the new line.

## delete

Deletes a line from the document.

Syntax:
delete <line_number>

Example:
delete 2

## display

Displays all lines currently stored in the document.

Syntax:
display

Example:
display

## search

Searches the document for a word or phrase.

Syntax:
search

Example:
search

The editor will ask for the word or phrase.

## help

Displays all available commands.

Syntax:
help

## quit

Exits the line editor.

Syntax:
quit
